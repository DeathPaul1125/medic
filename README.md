Un sistema moderno y responsivo para la **gestión de citas médicas**, desarrollado con **Laravel**, **Livewire** y **Flowbite**.  
Permite a los pacientes agendar citas, a los médicos gestionarlas, y a los administradores llevar control completo del flujo clínico.

---

## 🚀 Características principales

✅ Gestión de usuarios (pacientes, doctores, administradores)  
✅ Agenda interactiva con Livewire  
✅ Interfaz moderna y responsive (Flowbite + TailwindCSS)  
✅ Notificaciones de confirmación de citas  
✅ Panel de administración con estadísticas  
✅ Soporte para múltiples especialidades médicas  
✅ Autenticación y autorización seguras  
✅ Integración lista para APIs (ej. notificaciones por correo o WhatsApp)

---

## 🧩 Tecnologías utilizadas

| Componente | Descripción |
|-----------|--------------|
| **Laravel 12+** | Framework backend principal |
| **Livewire 3+** | Interactividad sin recargar la página |
| **Flowbite** | Componentes UI sobre TailwindCSS |
| **MySQL** | Base de datos |
| **Alpine.js** | Comportamiento ligero en el frontend |
| **TailwindCSS** | Framework CSS moderno y flexible |
